# EXP23.2 — Baseline sob carga no kernel original E404

**Data:** 18/10/2026. **Predecessor:** EXP23.1 `PASS_REAL` (sete sensores sysfs numéricos e `soc` sem valor); serviço `thermalservice` não fornece temperaturas (HAL Ready false). O kernel voltou ao original E404 `build-user@build-host #14 Aug23`, `rate_limit_us=2000` nas três políticas. **`FLASH_READY=false`.**

## Objetivo

Executar um único perfil de **3 minutos** em carga reproduzível, com 18 amostras em intervalo de 10 segundos. O PowerShell 5.1 coleta dados ADB **somente leitura** de `sysfs` thermal zones e `scaling_cur_freq`, salvando um CSV **somente no Windows**. Não coleta FPS: usar overlay confiável ou serviço de captura de frametimes separadamente, se disponível, e anotar configurações do jogo (resolução, gráficos, FPS cap, brilho, carregamento, taxa de atualização). A média simples de MHz da CPU não mede FPS ou power draw.

## Critério prévio

- Tablet Android `pipa`, slot `_b`, ADB `device`.
- `cat /proc/version` deve mostrar kernel persistente `build-user@build-host #14` e não o `runner #1`.
- Todas as três políticas `schedutil/rate_limit_us` devem retornar 2000.
- Abrir uma cena repetível do jogo ou aplicativo; usar mesma configuração nas séries futuras. Não iniciar EXP06 nem autorizar automaticamente novo `fastboot boot`.

## PowerShell — amostragem segura, sem pipe no shell remoto

```powershell
$adb = "C:\platform-tools\adb.exe"
$device = (& $adb shell getprop ro.product.device | Out-String).Trim()
$slot = (& $adb shell getprop ro.boot.slot_suffix | Out-String).Trim()
$ver = (& $adb shell cat /proc/version | Out-String).Trim()
$limits = @(& $adb shell "cat /sys/devices/system/cpu/cpufreq/policy*/schedutil/rate_limit_us" | Where-Object { $_ -match '^\d+$' })
if ($device -ne "pipa" -or $slot -ne "_b" -or $ver -notmatch 'build-user@build-host' -or
    $limits.Count -ne 3 -or @($limits | Where-Object { $_ -ne "2000" }).Count -gt 0) {
    throw "EXP23.2: baseline original nao confirmado; nao iniciar coleta."
}
$dest = Join-Path $env:USERPROFILE "Downloads\EXP23-E404-baseline.csv"
if (Test-Path -LiteralPath $dest) { throw "Arquivo ja existente: $dest. Preserve a rodada anterior." }
$script = 'for z in /sys/class/thermal/thermal_zone*; do t=$(cat $z/type 2>/dev/null); v=$(cat $z/temp 2>/dev/null); echo $t=$v; done'
for ($i=1; $i -le 18; $i++) {
    $sensor = @{}
    $raw = @(& $adb shell $script)
    if ($LASTEXITCODE -ne 0) { throw "EXP23.2: erro de sensor na amostra $i" }
    foreach ($line in $raw) {
        if ($line -match '^([a-zA-Z0-9_-]+)=(-?\d+)$') { $sensor[$Matches[1]] = $Matches[2] }
    }
    $freq = @(& $adb shell "cat /sys/devices/system/cpu/cpufreq/policy*/scaling_cur_freq" | Where-Object { $_ -match '^\d+$' })
    if ($LASTEXITCODE -ne 0) { throw "EXP23.2: erro cpufreq na amostra $i" }
    $row = [pscustomobject]@{
        time_iso=(Get-Date).ToString("o"); sample=$i;
        cpu_therm_raw=$sensor["cpu_therm"]; gpu0_raw=$sensor["gpuss-0-usr"];
        gpu1_raw=$sensor["gpuss-1-usr"]; pm8150_raw=$sensor["pm8150_tz"];
        battery_raw=$sensor["battery"]; batt_therm_raw=$sensor["batt_therm"];
        freq_policies_khz=($freq -join "/")
    }
    $row | Export-Csv -LiteralPath $dest -NoTypeInformation -Append -Encoding UTF8
    Write-Output "EXP23.2 SAMPLE=$i/18 CPU=$($sensor['cpu_therm']) GPU=$($sensor['gpuss-1-usr']) FREQ_KHZ=$($freq -join '/')"
    if ($i -lt 18) { Start-Sleep -Seconds 10 }
}
Write-Output "EXP23.2 E404 CSV=$dest"
```

O código usa apenas leitura de caminhos sysfs já conhecidos; o `|` de `Where-Object` e `Export-Csv` está no **Windows**, nunca embutido na string remota `echo`. Não altera parâmetros térmicos ou CPU. No CSV, valores são **brutos**, sem conversão de unidade durante a aquisição (caso o driver exponha escalas diferentes).

A pessoa usuária poderá escolher cenário fixo e reportar FPS e sensação subjetiva, mas **não** declarar causalidade de diferenças de performance a partir de um único ciclo. Ideal comparar A–B–A com iguais condições térmicas e repetições. É necessário **novo consentimento** para iniciar EXP06 novamente e repetir a carga, pois autorização EXP22.3 cobria uma tentativa já concluída.

## Critérios

`EXP23_E404_LOAD_CSV=PASS_REAL` requer saída do PowerShell com `SAMPLE=18/18`, arquivo CSV existente com 18 linhas de dados e sem erro de shell/ADB; se possível conferir amostra de arquivo. A EXP23.1 só confirma disponibilidade de sensores; não confunde o `soc=` vazio com 0. Não declarar `EXP23_PERFORMANCE_GAINS` sem FPS/framedrops de uma metodologia reproduzível.
