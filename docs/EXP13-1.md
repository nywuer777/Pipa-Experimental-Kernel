## EXP13.1 implementada

Arquivo: [`tools/exp13-1-avb-partition-names.ps1`](https://github.com/nywuer777/Pipa-Experimental-Kernel/blob/main/tools/exp13-1-avb-partition-names.ps1).

Fonte das estruturas: headers AOSP oficiais:
- `AvbVBMetaImageHeader` (offsets, flags, auth/aux);
- `AvbChainPartitionDescriptor` (tag 4; rollback location, nome, flags);
- `AvbHashDescriptor` (tag 2; image size, hash algorithm, partition name, flags);
- `AvbHashtreeDescriptor` (tag 1; filesystem image size, algorithm, partition name, flags).

O script é somente leitura e só aceita o SHA-256 original da partição `vbmeta_b.img`. Lê descritores com bounds-checking e imprime: tipo, nome seguro da partição, flags, rollback location para chains, tamanho e nome do algoritmo para hash/hashtree. Não imprime propriedades, chaves públicas, assinaturas, salts, roots ou digests. Não calcula se o payload do boot foi/é aceito pela cadeia de boot.

### Execução no computador do usuário

Após salvar o script `exp13-1-avb-partition-names.ps1` em Downloads:

```powershell
Copy-Item "$env:USERPROFILE\Downloads\exp13-1-avb-partition-names.ps1" "C:\platform-tools\exp13-1-run.ps1" -Force
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\platform-tools\exp13-1-run.ps1" -VbmetaPath "C:\platform-tools\pipa_backup\vbmeta_b.img"
```
